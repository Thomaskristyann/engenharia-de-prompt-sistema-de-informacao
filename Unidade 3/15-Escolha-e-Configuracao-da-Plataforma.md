# 15/10 — Escolha e Configuração da Plataforma

## Projeto: Feito!

### Integrantes
- Thomas Kristyann Santos Dias
- Igor Almeida dos Santos
- José Carlos Leite Silva

### Plataforma escolhida
Bubble.

### Justificativa
O Bubble foi escolhido por oferecer interface visual, banco de dados integrado e recursos para desenvolver aplicativos sem programação tradicional. O plano gratuito atende às necessidades do projeto.

### Configuração realizada
- Criação do ambiente de trabalho.
- Estruturação do banco de dados com o tipo de dado "Tarefa".
- Montagem da interface básica.
- Criação do formulário de cadastro.
- Teste inicial para verificar o registro correto de uma tarefa no banco de dados.

### Resultado
A configuração inicial foi concluída e o cadastro de tarefas foi testado com sucesso.
