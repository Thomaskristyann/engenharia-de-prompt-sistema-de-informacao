## 🎯 Objetivo da Disciplina

Esta disciplina explora as tendências atuais em Engenharia de Prompt e Inteligência Artificial aplicadas a Sistemas de Informação. Os alunos aprenderão técnicas avançadas de desenvolvimento de prompts, otimização de modelos de linguagem e implementação de soluções inteligentes.

## 📋 Conteúdo Programático

### Tópicos Principais
- Fundamentos de Engenharia de Prompt
- Modelos de Linguagem (LLMs) e suas aplicações
- Técnicas de Otimização de Prompts
- Integração de IA em Sistemas de Informação
- Tendências e Futuro da IA
- Ética e Responsabilidade em IA
- Casos de Uso Reais

## 🚀 Como Usar Este Repositório

### Pré-requisitos
- Conhecimento básico em programação
- Familiaridade com conceitos de IA/ML
- Acesso a APIs de modelos de linguagem (OpenAI, Anthropic, etc.)

### Instalação

```bash
# Clonar o repositório
git clone https://github.com/Thomaskristyann/engenharia-de-prompt-sistema-de-informacao.git

# Navegar para o diretório
cd engenharia-de-prompt-sistema-de-informacao

# Instalar dependências (se houver)
pip install -r requirements.txt
```
